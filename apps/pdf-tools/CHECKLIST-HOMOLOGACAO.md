# Checklist de Homologacao - SEPLAN PDF

Use este checklist antes de publicar na Central SEPLAN.

## Navegadores

- [ ] Chrome atualizado
- [ ] Edge atualizado
- [ ] Teste em maquina padrao da prefeitura
- [ ] Teste em tela pequena/notebook

## Arquivos de teste

- [ ] PDF pequeno, ate 5 MB
- [ ] PDF medio, 20 MB a 80 MB
- [ ] PDF grande, acima de 100 MB
- [ ] PDF escaneado
- [ ] PDF com texto pesquisavel
- [ ] PDF com formulario preenchido
- [ ] PDF com paginas em retrato e paisagem
- [ ] Imagens JPG e PNG para converter em PDF

## Ferramentas principais

- [ ] Juntar
- [ ] Compactar
- [ ] Dividir
- [ ] Extrair
- [ ] Organizar
- [ ] Girar
- [ ] Marca d'agua
- [ ] Numerar
- [ ] PDF para JPG
- [ ] JPG/PNG para PDF
- [ ] Cortar
- [ ] Assinar visualmente
- [ ] Texto/carimbo
- [ ] Tarjar
- [ ] Comparar
- [ ] PDF para TXT
- [ ] Achatar formularios
- [ ] Metadados
- [ ] Capa
- [ ] 2/4 paginas por folha

## Seguranca e LGPD

- [ ] Confirmar que os arquivos nao sao enviados ao servidor
- [ ] Confirmar que nenhum arquivo fica salvo apos recarregar a pagina
- [ ] Validar texto institucional de privacidade
- [ ] Validar limite recomendado de 120 MB por operacao
- [ ] Validar bloqueio preventivo acima de 250 MB por operacao

## Publicacao

- [ ] Pasta `vendor` publicada junto do app
- [ ] `index.html`, `styles.css` e `app.js` acessiveis na rota final
- [ ] Download de arquivos funcionando
- [ ] Nenhum erro no console do navegador
- [ ] Link adicionado na Central SEPLAN
